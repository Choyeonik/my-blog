작성한 글은 완성된 HTML 페이지로 만들어져 작업 폴더의 posts 폴더에 저장됩니다.

ⓘ 이 저장 기능은 Chrome / Edge 같은 Chromium 계열 브라우저에서만 동작합니다 (Safari, Firefox는 지원하지 않음). 먼저 블로그 작업 폴더(이 write.html 파일이 들어있는 폴더)를 연결해주세요. 이후에는 같은 브라우저에서 다시 방문해도 자동으로 그 폴더에 연결됩니다. 비밀번호가 설정되어 있다면 연결 후 비밀번호 확인 화면이 나타납니다. (posts 폴더가 없다면 첫 저장 시 자동으로 만들어집니다.)

비밀번호를 입력해주세요

선택하지 않으면 홈 화면에 자동 생성된 무늬가 대신 표시됩니다.
