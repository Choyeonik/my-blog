클로드 코드 설치와 네 가지 모드, 스킬 정리

윈도우에 클로드 코드를 설치하고, Manual·Accept Edits·Plan·Auto 네 가지 모드와 스킬 기능을 배우며 정리한 글.

2026-08-31
수정하기 →

오늘은 윈도우 PC에 클로드 코드(Claude Code)를 처음 설치해서 사용해봤고, 네 가지 실행 모드와 스킬 기능을 배웠다.

1. 클로드 코드 설치
2. 네 가지 모드
3. 스킬

클로드 코드 설치

윈도우 환경에 클로드 코드를 설치했다. 터미널(CLI)에서 바로 명령을 내리면 AI가 실제로 내 컴퓨터의 작업 영역 내에서 권한을 가져 파파일을 읽고 고칠 수 있다.

답변 모드

클로드 코드는 얼마나 스스로 판단해서 작업을 진행할지에 따라 크게 네 가지 모드로 나뉜다.

모드 설명
Manual Mode 파일을 바꾸거나 지우는 등 무언가를 하기 전에 먼저 물어보는 모드
Accept Edits Mode AI가 묻지 않고 스스로 파일을 변경·수정하는 모드. 다 해주는 대신 끌려다닐 수 있음
Plan Mode 지금 처한 상황이 뭔지 계획만 세우고, 파일은 고치지 않는 모드
Auto Mode 대부분 묻지 않고 진행하는 모드

네 모드를 써보면서 Manual Mode와 Plan Mode로 상황 파악과 계획을 먼저 끝낸 뒤, Accept Edits Mode로 넘어가는 순서가 편하다는 걸 알게 됐다. 처음부터 Accept Edits Mode나 Auto Mode를 쓰면 AI가 알아서 다 진행해버려서 무슨 작업이 벌어지고 있는지 놓치고 끌려다니기 쉬웠다.

스킬(Skill)

클로드 코드에는 반복되는 작업을 미리 정해둔 절차대로 실행해주는 스킬 기능이 있다. 오늘은 배운 내용을 블로그 글로 정리해서 올리는 데 스킬을 사용해봤다.

스킬로 글을 올리는 과정에서 공부 자료에서 제공받은 CLAUDE.md파일에는 Jekyll 기반(_posts/ 폴더, Front Matter)으로 글을 쓰라고 적혀 있었지만, 실제 이 블로그는 posts/manifest.json과 HTML 파일로 관리되는 다른 방식이었다. 문서와 실제 구조가 달라서 어떤 방식으로 올릴지 다시 확인하고 진행했다. 앞으로 스킬을 쓰다가 오류가 생기면 이 글에 시행착오로 계속 추가할 예정이다.

오늘 정리

  • 윈도우에 클로드 코드를 설치했다.
  • Manual / Accept Edits / Plan / Auto, 네 가지 모드의 차이와 활용 순서를 배웠다.
  • 스킬로 블로그 글을 올리는 방법을 처음 써봤다.
