배운 것

HTML 완전 정복: 기본 구조부터 폼 처리까지

부트캠프 강의에서 HTML의 기본부터 심화까지 모든 태그와 개념을 배우며 실습한 내용입니다. 웹의 뼈대를 만드는 HTML의 전체 과정을 정리했습니다.

2026-09-06

들어가며 (Situation)

웹 개발의 첫 시작은 HTML을 이해하는 것이다. HTML은 웹사이트의 뼈대를 만드는 언어로, 모든 웹페이지의 기초가 된다. 부트캠프에서 HTML의 모든 주요 태그와 개념을 배우고 실습하면서, 단순히 태그를 외우는 것이 아니라 각 태그가 어떤 목적으로 사용되는지, 언제 사용해야 하는지를 이해하게 되었다.

학습 범위 (Task)

이 과정에서는 HTML의 기본 구조부터 시작해서 제목, 단락, 목록, 표, 이미지, 미디어, 링크, 그리고 사용자 입력을 받는 폼까지 거의 모든 주요 태그를 학습했다. 특히 각 태그의 속성과 실제 활용 방법, 그리고 서버와의 통신 방식까지 이해해야 했다.

학습 과정 (Action)

1. HTML의 기본 개념

HTML(HyperText Markup Language)은 웹 페이지를 작성하는데 사용되는 표준 마크업 언어다. 웹 페이지의 구조와 콘텐츠를 정의하며, 웹 브라우저는 HTML 문서를 해석하여 사용자에게 시각적으로 표시한다.

HTML은 요소(element)라고 불리는 태그(tag)를 사용하여 텍스트, 이미지, 링크, 리스트, 테이블 등 다양한 종류의 콘텐츠를 구성할 수 있다.

HTML 문서의 기본 구조

<!DOCTYPE html>
<html lang="ko">
<head>
    <meta charset="UTF-8">
    <meta http-equiv="X-UA-Compatible" content="IE=edge">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>페이지 제목</title>
</head>
<body>
    <!-- 웹 페이지의 콘텐츠 내용을 이곳에 작성 -->
</body>
</html>
  • <!DOCTYPE html>: 문서가 HTML5임을 선언
  • <html>: 문서의 시작과 끝
  • <head>: 문서의 메타데이터, 제목, 외부 스크립트 및 스타일 시트 정보
  • <body>: 웹 페이지의 실제 콘텐츠

HTML 주의사항

  • 태그는 대소문자를 구분하지 않으며, 소문자를 권장한다.
  • 시작 태그로 시작하면 반드시 종료 태그로 종료한다.
  • 파일 확장자는 반드시 html로 설정할 것
  • 문자의 공백은 한 개만 인식되며, 추가 공백을 위해서는 &nbsp;를 사용한다.

2. 텍스트 관련 태그

HTML에서 텍스트를 다루는 다양한 방법을 배웠다.

주석(Comment)

<!-- 한 줄 주석 -->

<!--
 여러 줄 주석
 작성하기
-->

제목, 단락, 줄바꿈

  • <h1>~<h6>: 제목 (h1이 가장 크고 h6이 가장 작음)
  • <p>: 단락 (자동 개행과 공백 처리)
  • <pre>: 입력한 그대로 출력 (띄어쓰기, 들여쓰기, 줄바꿈 유지)
  • <br>: 줄바꿈
  • <hr>: 수평선

글자 형태

  • <strong>: 의미적 강조 (중요한 내용)
  • <b>: 시각적 강조만
  • <em>: 강조의 의미
  • <i>: 기술 용어나 책 제목 같은 기울임
  • <mark>: 형광펜 효과
  • <u>: 밑줄
  • <small>: 작은 글씨 (부가 정보)
  • <sub>: 아래첨자
  • <sup>: 윗첨자
  • <s>: 취소선
  • <code>: 컴퓨터 코드
  • <kbd>: 키보드 입력
  • <blockquote>, <q>: 인용구
  • <cite>: 참고 출처
  • <abbr>: 약자 (마우스 호버 시 설명 표시)

3. 목록 태그

순서 없는 목록 (ul)

<ul>
    <li>항목1</li>
    <li>항목2</li>
    <li>항목3</li>
</ul>

순서 있는 목록 (ol)

<ol type="a">
    <li>항목1</li>
    <li>항목2</li>
</ol>

type 속성: 1(숫자), a(소문자), A(대문자), i(소문자 로마자), I(대문자 로마자)

설명 목록 (dl)

<dl>
    <dt>용어</dt>
    <dd>설명</dd>
</dl>

4. 표 태그

기본 구조

<table border="1">
    <tr>
        <th>제목1</th>
        <th>제목2</th>
    </tr>
    <tr>
        <td>내용1</td>
        <td>내용2</td>
    </tr>
</table>
  • <table>: 표
  • <tr>: 행(row)
  • <th>: 표 제목 (중앙 정렬, 굵게)
  • <td>: 표 데이터
  • <caption>: 표 제목

표 속성

  • border: 테두리 두께
  • colspan: 열 병합
  • rowspan: 행 병합
  • width, height: 크기 지정

상세 구조

  • <thead>: 테이블 헤더 (1개만)
  • <tbody>: 테이블 본문 (여러 개 가능)
  • <tfoot>: 테이블 푸터 (1개만)

5. 영역 및 시맨틱 태그

블록 요소와 인라인 요소

  • 블록 요소: 좌우 공간을 모두 차지 (div, p, h1~h6 등)
  • 인라인 요소: 필요한 공간만 차지 (span, a, strong 등)

영역 분할 태그

  • <div>: 블록 요소로 공간을 수직 분할
  • <span>: 인라인 요소로 공간을 수평 분할

시맨틱 태그 (의미론적 HTML)

  • <header>: 문서의 머릿글
  • <nav>: 네비게이션 메뉴
  • <main>: 문서의 본문 (유일해야 함)
  • <article>: 독립적인 콘텐츠
  • <section>: 문서의 부분/주제별 그룹
  • <aside>: 옆에 위치하는 사이드바
  • <footer>: 문서의 바닥
  • <figure>, <figcaption>: 사진 및 설명

6. 이미지 태그

<img src="이미지경로" alt="이미지설명" width="200px" height="100px">

주요 속성

  • src: 이미지 경로 (필수)
  • alt: 이미지 설명 (필수) - 접근성, SEO, 의미 전달
  • width, height: 크기

경로 관리

  • 절대 경로: 전체 URL (https://...)
  • 상대 경로: 현재 파일 기준 (./, ../)

7. 미디어 태그

오디오

<audio controls loop>
    <source src="music.mp3" type="audio/mpeg">
</audio>

비디오

<video width="640" height="360" controls autoplay muted>
    <source src="video.mp4" type="video/mp4">
</video>

주요 속성

  • controls: 플레이어 컨트롤 표시
  • autoplay: 자동 재생
  • loop: 반복 재생
  • muted: 음소거

8. 하이퍼링크 태그

<a href="https://www.google.com" target="_blank">구글</a>

주요 속성

  • href: 링크 주소 (필수)
  • target="_blank": 새 탭에서 열기
  • target="_self": 현재 탭에서 열기 (기본값)

페이지 내 이동

<a href="#section1">섹션1로 이동</a>
<h2 id="section1">섹션1</h2>

9. 폼 태그

기본 폼 구조

<form action="서버주소" method="get/post">
    <input type="text" name="username">
    <button type="submit">제출</button>
</form>

주요 속성

  • action: 데이터를 처리할 서버 주소
  • method="get": URL에 데이터 첨부 (크기 제한, 보안 낮음)
  • method="post": 별도로 전송 (크기 무제한, 보안 높음)

입력 양식 태그

  • <input type="text">: 텍스트 입력
  • <input type="password">: 비밀번호
  • <input type="checkbox">: 체크박스
  • <input type="radio">: 라디오 버튼
  • <input type="email">: 이메일
  • <input type="date">: 날짜
  • <input type="file">: 파일 선택
  • <select>: 드롭다운 메뉴
  • <textarea>: 다중 라인 텍스트
  • <button type="submit">: 제출 버튼

10. 실습 프로젝트

강의를 진행하면서 여러 실습 과제를 완성했다:

  • 공연 요금표: 복잡한 표 구조로 colspan, rowspan 활용
  • 식단표: 주간 식단 정보를 표로 정리
  • 복잡한 표 구조: 다양한 병합 방식 적용
  • 네이버 검색 폼: GET 방식 폼으로 실제 서버 연결

결과 (Result)

Before: 태그만 아는 수준

  • 각 태그의 이름만 알고 용도 구분 불명확
  • 속성의 중요성을 미처 인식하지 못함
  • 서버와의 통신 개념 부족

After: 웹 문서 구조 전체 이해

  • 각 태그의 목적과 사용 상황을 명확히 이해
  • 속성을 활용한 풍부한 표현 방법 습득
  • 폼을 통한 사용자 입력과 서버 통신 메커니즘 이해
  • 의미론적 HTML의 중요성 깨달음

이 과정을 통해 HTML은 단순한 태그의 나열이 아니라 웹 문서의 구조와 의미를 담는 언어임을 깨달았다. 웹 개발의 다음 단계인 CSS와 JavaScript를 배울 때, 이 견고한 HTML 기초가 얼마나 중요할지 충분히 예상할 수 있다.

더 학습하면 좋은 개념

  • HTML5 신규 태그 — <video>, <audio>, <canvas>, <svg> 등 HTML5에서 추가된 태그들. 이전에는 플러그인이 필요했던 작업들을 네이티브로 처리 가능하다.
  • 웹 접근성(Web Accessibility) — alt 속성, ARIA 속성, 시맨틱 태그 등을 통해 장애인도 웹사이트를 쉽게 이용할 수 있게 만드는 방법. 법적 의무이자 윤리적 책임이다.
  • SEO (검색 엔진 최적화) — 구글, 네이버 같은 검색 엔진이 웹사이트를 올바르게 이해하도록 하는 방법. 시맨틱 태그와 메타 데이터가 중요하다.
  • CSS를 통한 스타일링 — HTML은 구조를 담당하고 CSS는 디자인을 담당한다. HTML 구조가 명확해야 CSS 적용도 정확하고 간편해진다.
  • JavaScript를 통한 상호작용 — 폼 유효성 검사, DOM 조작, 이벤트 처리 등으로 사용자와 상호작용하는 동적 웹페이지를 만드는 방법.
