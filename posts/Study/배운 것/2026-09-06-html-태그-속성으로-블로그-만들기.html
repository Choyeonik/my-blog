배운 것

HTML 태그의 속성을 활용해 나만의 블로그 페이지 만들기

프론트엔드 기초를 배우기 위해 HTML을 학습하면서 태그의 속성을 활용해 나만의 블로그 페이지를 만들어보았습니다. 기본 태그부터 시행착오까지의 전 과정을 정리했습니다.

2026-09-06

들어가며 (Situation)

프론트엔드 개발자가 되기 위한 첫 걸음은 웹의 뼈대를 이해하는 것이다. 홈페이지가 어떻게 구성되는지 직접 만들어보면서 배워야 실무에서 CSS와 JavaScript를 다룰 때도 명확한 기초를 가질 수 있다. 이 경험을 통해 HTML의 기본 태그들이 단순한 텍스트 표시가 아니라, 웹 문서의 구조를 정의하는 중요한 역할을 한다는 것을 깨닫게 되었다.

문제 상황 (Task)

단순히 "홈페이지를 만들어보세요"라는 과제는 막연했다. 어떤 태그를 사용해야 하고, 어떻게 연결하고, 어떻게 콘텐츠를 표현해야 할까? 특히 텍스트, 목록, 이미지, 링크를 모두 조합해서 하나의 완성된 페이지로 만드는 것이 처음에는 어려웠다. 또한 단순히 화면에 보이도록 하는 것뿐만 아니라, 의미 있는 마크업으로 웹 표준에 맞게 작성해야 한다는 요구사항도 있었다.

해결 과정 (Action)

1. HTML 문서의 기본 골격 이해

먼저 모든 HTML 문서는 다음과 같은 기본 구조를 가진다는 것을 배웠다.

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>페이지 제목</title>
</head>
<body>
    <!-- 콘텐츠가 여기에 들어간다 -->
</body>
</html>

<!DOCTYPE html>은 이 문서가 HTML5 표준임을 브라우저에 알리고, <meta charset="UTF-8">은 한글 같은 다국어가 제대로 표시되도록 보장한다. 이 기본 틀 없이는 웹페이지가 제대로 렌더링되지 않는다.

2. 텍스트 콘텐츠 구조화하기

초반에는 모든 글을 <p> 태그로 작성했지만, 문제가 생겼다. 페이지에 여러 섹션이 있을 때 어디서 어디까지가 하나의 주제인지 구분이 안 되었다. 이를 해결하기 위해 제목 태그를 활용했다.

<h1>박서준</h1>
<p>부트캠프에서 웹을 배우고 있습니다.</p>

<h3>좋아하는 것</h3>
<ul>
    <li>커피 내리기</li>
    <li>영화 보기</li>
    <li>주말 산책</li>
</ul>

<h3>배우고 싶은 순서</h3>
<ol>
    <li>HTML</li>
    <li>CSS</li>
    <li>JavaScript</li>
</ol>

<h1>은 페이지의 주제(이름), <h3>은 섹션의 부제목으로 사용했다. 이렇게 하면 화면에 시각적으로 계층이 보이고, 스크린 리더 사용자도 문서 구조를 이해할 수 있다.

3. 태그의 속성으로 더 풍부한 표현하기

기본 <p> 태그 안의 텍스트만으로는 강조가 부족했다. 동일한 "굵게"를 표현하는 <strong>과 <b>, 기울임을 하는 <em>과 <i> 사이의 차이를 배웠다.

  • <strong> vs <b>: strong은 의미적 강조 (중요한 내용), b는 시각적 강조만 담당
  • <em> vs <i>: em은 강조의 의미, i는 기술 용어나 책 제목 같은 기울임 스타일
<p><strong>중요한 공지사항:</strong> 다음 주부터 수강 가능합니다.</p>
<p>이 책은 <i>웹 표준</i>의 중요성을 설명한다.</p>

이 차이를 이해하면서 "왜 같은 결과인데 다른 태그가 필요할까?"라는 질문에 대한 답을 얻었다. 검색 엔진과 접근성 도구가 <strong>을 더 중요하게 인식하기 때문이다.

4. 링크와 이미지로 상호작용 추가

정적인 텍스트만으로는 블로그가 완성되지 않았다. 다른 사이트로의 링크와 이미지가 필요했다.

<h3>링크</h3>
<ul>
    <li><a href="https://www.google.com">구글 검색</a></li>
    <li><a href="https://github.com">깃허브</a></li>
    <li><a href="https://choyeonik.github.io/my-blog/index.html">내 블로그</a></li>
</ul>

<h3>좋아하는 것</h3>
<ul>
    <li>커피 내리기 <img src="sample/image/flower1.PNG" alt="커피내리기"></li>
    <li>영화 보기 <img src="sample/image/flower4.PNG" alt="영화 보기"></li>
    <li>주말 산책 <img src="sample/image/flower3.PNG" alt="주말 산책"></li>
</ul>

<a> 태그의 href 속성으로 URL을 지정하고, <img> 태그의 src 속성으로 이미지 경로를, alt 속성으로 이미지 설명을 추가했다. 특히 alt 속성은 이미지가 로드되지 않았을 때나 시각 장애인용 스크린 리더가 읽을 수 있도록 해준다.

5. 영역 태그로 섹션 구분하기

여러 사람의 정보를 한 페이지에 표시할 때, 각 사람의 정보가 시각적으로 분리되어야 했다. 이때 <div> 태그를 사용했다.

<div>
    <h1>박서준</h1>
    <p>부트캠프에서 웹을 배우고 있습니다.</p>
    <h3>좋아하는 것</h3>
    <ul>
        <li>커피 내리기</li>
    </ul>
</div>

<hr>

<div>
    <h1>김서연</h1>
    <p>안녕하세요.</p>
</div>

<div>는 콘텐츠를 그룹화하는 역할을 하고, <hr>로 시각적 구분선을 추가했다. 이 구조 덕분에 나중에 CSS로 스타일을 입힐 때 각 섹션을 독립적으로 꾸밀 수 있게 되었다.

6. 시행착오: 의미 있는 마크업의 중요성

처음에는 단순히 "화면에 보이면 된다"는 생각으로 <b> 대신 <strong>을, 장식용 <hr> 태그를 마구 사용했다. 하지만 강의를 진행하면서 웹 표준과 접근성의 중요성을 깨달았다. 스크린 리더 사용자가 내 페이지를 사용할 때, 또는 검색 엔진이 내 콘텐츠를 색인화할 때, 단순한 시각 효과가 아니라 구조화된 의미가 얼마나 중요한지 알게 되었다.

결과 (Result)

Before: 첫 시도

  • 모든 콘텐츠가 <p> 태그로 평탄하게 작성됨
  • 강조나 시각적 구분이 부족함
  • 링크와 이미지는 있지만 구조화되지 않음

After: 최종 완성

  • 의미 있는 제목 태그로 계층 구조 형성
  • 의미적 마크업(<strong>, <em>) 사용
  • 목록 태그로 정보를 체계적으로 조직화
  • alt 속성으로 접근성 확보
  • <div>로 논리적 섹션 분리

이 과정을 통해 첫 번째 블로그 페이지를 완성했고, HTML은 단순한 텍스트 표시 언어가 아니라 웹 문서의 의미를 정의하는 언어임을 이해하게 되었다. 이제 다음 단계인 CSS로 스타일을 입히고, JavaScript로 상호작용을 추가할 때도 이 견고한 HTML 기초가 있으면 훨씬 수월할 것 같다.

더 학습하면 좋은 개념

  • Semantic HTML (의미론적 HTML) — <div> 대신 <header>, <nav>, <main>, <footer> 같은 의미 있는 태그를 사용하면 코드의 의도가 더 명확해진다. 접근성과 SEO 측면에서도 중요하다.
  • 웹 접근성(Web Accessibility, a11y) — 시각, 청각, 운동 장애가 있는 사용자도 웹사이트를 사용할 수 있도록 만드는 것이다. alt 속성, <label> 태그, 키보드 네비게이션 등이 포함된다. WCAG 지침을 참고하면 좋다.
  • SEO (검색 엔진 최적화) — 구글, 네이버 같은 검색 엔진이 내 웹사이트를 올바르게 이해하도록 HTML을 작성하는 방법. <title>, <meta> 태그, 제목 태그의 계층 구조가 중요하다.
  • HTML 폼 요소 — <form>, <input>, <textarea>, <select> 등으로 사용자 입력을 받는 방법. 블로그에 댓글 기능이나 회원가입 페이지를 만들 때 필수다.
  • 메타데이터와 Open Graph — <meta> 태그 중 특히 og:title, og:image, og:description 등으로 소셜 미디어에서 링크 공유 시 보여지는 미리보기를 정의할 수 있다.
