[2026-08-26] Git 기본 개념 및 실습

Git과 Git Hub을 이용하여 협업 시 필요한 개념과 방법을 실습하며 배운 것을 정리하였다.

2026-08-30

이번 포스팅에선 Git과 Git Hub을 이용하여 작업 관리 방법을 알아보려고 한다.

1. 버전 관리 기본 개념
2. 브랜치 활용
3. 어려웠던 점

Git은 작업 시 보다 다양한 기능을 보조하는 ClI 도구이다.

명령 기능
add Staging Area로 작업물 이동
commit 파일 상태와 시점 저장
push 작업물을 저장소로 이동
pull 저장소에서 작업물을 갖고 옴

브랜치

브랜치는 협업 작업에서 같은 작업물을 동시에 작업 시 서로 다른 영역에서 작업하여 저장할 수 있는 작업 영역이다.

브랜치를 쓰는 이유

같은 파일을 여러 명이서 동시에 작업하게 되면 내용물이 달라지게 되는데, 보다 편리하게 관리하기 위해 사용한다.

브랜치로 서로 자기만의 영역에서 작업 후 Git Hub와 같은 저장소에 Push하게 되면, 각자 Push한 파일들을 확인 후 최종본을 하나로 Merge 한다.

여기서 서로 파일을 보며 잘못된 부분이 있으면 PR을 작성하고 반려하거나 Merge를 한다.

막혔던 것

브랜치 사용 시 Clone과 Pull의 차이를 몰랐다. 두 명령 모두 내려받는 것이라 동일하게 받아들였는데, 응용 실습을 통해 알게되었다.

응용 실습을 통해 Clone은 저장소에 있는 작업물을 로컬로 처음 내려받을 때 사용하는 것이고,
Pull은 내려받은 작업물의 버전을 최신화 할 때 사용하는 것 이었다.
