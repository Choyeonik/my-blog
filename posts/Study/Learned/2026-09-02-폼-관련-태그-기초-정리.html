폼 관련 태그 기초 정리

HTML에서 사용자와 상호작용하는 폼(Form) 요소들의 다양한 타입과 용도를 학습한 내용입니다. input, select, textarea 등의 태그를 실습하며 각각의 역할과 속성을 정리했습니다.

2026-09-02

HTML에서 사용자의 입력을 받기 위한 폼(Form) 요소들을 학습했습니다. 웹 사이트가 일방적인 정보 제공이 아닌 사용자와의 상호작용을 담당하는 것에서 폼의 역할이 중요함을 알게 되었습니다.

Form 태그란?

form 태그는 HTML에서 사용자가 값을 입력할 수 있는 양식을 제공하는 태그입니다. 검색창, 로그인 화면, 회원가입 폼 등 사용자의 정보를 입력받아 서버로 전송하는 역할을 합니다.

form 태그 내부에서 input, select, textarea 같은 태그들을 활용하여 사용자가 입력한 데이터를 서버로 전달합니다.

form 태그의 주요 속성

속성 설명 예시
action 폼의 입력된 값들을 전송받을 서버의 주소 action="https://search.naver.com/search.naver"
method 서버에 데이터를 전송하는 방식 (GET 또는 POST) method="post"
enctype 폼 데이터의 인코딩 방식 (파일 업로드 시 필요) enctype="multipart/form-data"

input 태그의 다양한 타입

input 태그의 type 속성은 어떤 종류의 입력을 받을지 결정합니다. 각 타입마다 고유한 기능을 제공합니다.

텍스트 관련 타입

  • type="text": 한 줄의 텍스트 입력 필드
    • placeholder 속성으로 입력 힌트 제공 가능
    • size 속성으로 입력창 너비 조절 가능
  • type="password": 비밀번호 입력 필드
    • 입력한 문자가 화면에 노출되지 않음
  • type="email": 이메일 입력 필드
    • 자동으로 이메일 형식 검증
  • type="tel": 전화번호 입력 필드
  • type="url": URL 입력 필드
  • type="search": 검색 입력 필드

예시 코드:

<form action="#" method="post">
    <label for="userId">아이디 : </label>
    <input type="text" id="userId" name="userId"
           size="60" placeholder="아이디를 입력해주세요">

    <label for="userPwd">비밀번호 : </label>
    <input type="password" id="userPwd" name="userPwd"
           size="40" placeholder="비밀번호를 입력해주세요">

    <button type="submit">로그인</button>
</form>

숫자와 범위 관련 타입

  • type="number": 숫자만 입력 가능
    • min, max 속성으로 범위 지정
    • step 속성으로 증감 단위 지정
  • type="range": 슬라이더로 범위 내 값 선택
    • 마우스로 드래그하여 값을 선택

예시 코드:

<form action="#" method="get">
    <label>수량 : </label>
    <input type="number" name="amount" min="0" max="10" value="0" step="1">
    <br>
    <label>점수 : </label>
    <input type="range" name="point" min="0" max="100" value="50">
    <br>
    <button type="submit">전송</button>
</form>

날짜와 시간 관련 타입

  • type="date": 년/월/일 선택
  • type="month": 년/월 선택
  • type="week": 주(week) 단위 선택
  • type="time": 시간/분 선택
  • type="datetime-local": 년/월/일/시간/분 선택

예시 코드:

<form action="#">
    <label>날짜 : </label>
    <input type="date" name="date"><br>

    <label>시간 : </label>
    <input type="time" name="time"><br>

    <label>정확한 시각 : </label>
    <input type="datetime-local" name="datetime"><br>

    <button type="submit">전송</button>
</form>

선택 및 체크 관련 타입

  • type="radio": 라디오 버튼 (단일 선택)
    • 같은 name 속성을 가진 라디오 버튼들은 그룹을 이루며, 하나만 선택 가능
  • type="checkbox": 체크박스 (중복 선택)
    • 여러 개를 동시에 선택 가능
  • type="color": 색상 선택
  • type="file": 파일 업로드
    • multiple 속성으로 여러 파일 동시 선택 가능

라디오 버튼 예시 (단일 선택):

<form action="#">
    <fieldset>
        <legend>성별</legend>
        <label>
            <input type="radio" name="gender" value="남성"> 남성
        </label>
        <label>
            <input type="radio" name="gender" value="여성"> 여성
        </label>
    </fieldset>
    <button type="submit">제출</button>
</form>

체크박스 예시 (중복 선택):

<form>
    <fieldset>
        <legend>취미</legend>
        <label>
            <input type="checkbox" name="hobby" value="야구" checked> 야구
        </label>
        <label>
            <input type="checkbox" name="hobby" value="농구"> 농구
        </label>
        <label>
            <input type="checkbox" name="hobby" value="축구"> 축구
        </label>
    </fieldset>
    <button type="submit">제출</button>
</form>

버튼 관련 타입

  • type="submit": 폼 제출 버튼
  • type="reset": 폼 초기화 버튼 (모든 입력값 지우기)
  • type="button": 일반 버튼 (기본 동작 없음, JavaScript로 커스터마이징 가능)
  • type="hidden": 화면에 표시되지 않는 숨겨진 데이터 필드

select & option 태그

select 태그는 드롭다운 메뉴를 만드는 태그입니다. 사용자가 여러 옵션 중 하나를 선택할 수 있게 해줍니다.

  • <option value="값">: 각 선택 옵션
  • selected 속성: 기본으로 선택되는 옵션 지정
  • size 속성: 한 번에 보이는 옵션의 개수
  • multiple 속성: 여러 개 동시 선택 가능

기본 select 예시:

<form action="#">
    <label>국적 : </label>
    <select name="nation">
        <option value="ko">한국</option>
        <option value="ch">중국</option>
        <option value="jp" selected>일본</option>
        <option value="etc">그 외</option>
    </select>
    <button type="submit">제출</button>
</form>

중요한 개념: 화면에 표시되는 텍스트(한국, 중국, 일본)와 서버에 전송되는 value 속성값(ko, ch, jp)은 다릅니다. 개발자는 value를 기준으로 데이터를 처리합니다.

textarea 태그

textarea는 여러 줄의 텍스트를 입력받을 수 있는 태그입니다. input type="text"는 한 줄만 가능하지만, textarea는 세로와 가로 크기를 조절할 수 있습니다.

  • cols 속성: 가로 너비 (문자 개수)
  • rows 속성: 세로 높이 (줄 개수)

예시 코드:

<form action="#">
    <label for="comment">의견을 남겨주세요 : </label>
    <textarea id="comment" name="comment" cols="50" rows="5"
              placeholder="여러 줄의 의견을 작성할 수 있습니다"></textarea>
    <button type="submit">제출</button>
</form>

datalist 태그

datalist는 input 요소와 함께 사용하여 입력 중에 추천 목록을 제공하는 태그입니다. 사용자가 입력할 때마다 일치하는 항목들이 자동으로 표시됩니다.

예시 코드:

<form action="#">
    <label for="browser">브라우저 선택 : </label>
    <input type="text" id="browser" name="browser" list="browserList">

    <datalist id="browserList">
        <option value="Chrome">
        <option value="Firefox">
        <option value="Safari">
        <option value="Edge">
    </datalist>

    <button type="submit">제출</button>
</form>

fieldset & legend 태그

fieldset은 폼의 요소들을 논리적으로 그룹화하는 태그이고, legend는 그 그룹에 제목을 붙이는 태그입니다.

예시 코드:

<form action="#">
    <fieldset>
        <legend>개인정보</legend>
        <label>이름 : <input type="text" name="name"></label><br>
        <label>이메일 : <input type="email" name="email"></label><br>
    </fieldset>

    <fieldset>
        <legend>선택사항</legend>
        <label>뉴스레터 구독 : <input type="checkbox" name="newsletter"></label><br>
    </fieldset>

    <button type="submit">제출</button>
</form>

GET vs POST 방식

form 태그의 method 속성으로 지정합니다.

구분 GET POST
데이터 노출 URL에 노출됨 숨겨짐 (보안)
데이터 크기 제한 제한 있음 (URL 길이) 제한 없음
용도 검색, 필터링 로그인, 회원가입, 데이터 변경
기본값 method 미지정 시 기본 명시적으로 지정

실제 예시 - 네이버 검색 폼 (GET 방식):

<form action="https://search.naver.com/search.naver" method="get">
    <h3>🔍 네이버 검색</h3>
    <input type="text" name="query" placeholder="검색어를 입력하세요" required>
    <button type="submit">검색</button>
</form>

이 폼을 제출하면 URL이 https://search.naver.com/search.naver?query=검색어로 변경됩니다.

배운 점

폼 요소들을 학습하면서 웹에서 사용자와의 상호작용이 얼마나 중요한지 깨달았습니다.

  • 각 input type의 역할 이해: 단순한 텍스트 입력뿐만 아니라 숫자, 날짜, 색상, 파일 등 다양한 타입이 각자의 용도에 최적화되어 있습니다.
  • data 속성값의 중요성: 사용자에게 보이는 텍스트와 서버에 전송되는 value는 다르며, 개발자는 value를 기준으로 데이터를 처리합니다.
  • form의 보안성: GET과 POST 방식의 차이를 이해하고 상황에 맞는 방식을 선택하는 것이 중요합니다.
  • 사용자 경험 개선: placeholder, label, fieldset 등을 올바르게 사용하면 사용자가 폼을 더 쉽게 이해하고 사용할 수 있습니다.
