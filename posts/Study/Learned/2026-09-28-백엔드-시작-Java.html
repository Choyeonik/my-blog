백엔드 시작: Java

Java에 대해 첫 단계, IntellJ를 이용하여 연산자와 리터럴, 형변환 등 기초적인 부분에 대한 글

오늘은 백엔드 개발 전 개념에 대해 IntelliJ를 이용하여 배운 것을 포스팅하려한다.

  1. JDK 개념
  2. 리터럴에 대해
  3. 형변환에 대해
  4. 연산자에 대해

JDK 설치

윈도우 환경에 사용할 수 있는 JDK 21 LTS를 설치하였다.

개발 환경에서는 JDK 개발 버전이 달라지면 현재 개발하던 서비스에 충돌 문제가 발생할 수 있어서, 최신버전이 나와도 원래 쓰던 고전 버전을 계속해서 사용한다고 한다.

이번에 내가 사용할 JDK 버전은 JDK 21-LTS이다.

JDK에 대해서

JDK는 "자바 개발 키트" 이다.
JDK 내에는 JRE, JVM 가 있고 JRE는 Java 애플리케이션을 실행하기 위한 환경이고 JRE 하위에 있는 JVM은 Java 바이트 코드를 실행하는 가상머신이다.

IntelliJ

IntelliJ를 이용한 Java 강의가 진행되었다.
폴더 생성을 할 때에 3-STEP 구조를 이용하여 폴더를 만든다.
맨 위 폴더는 회사의 종류(com, org...)
두 번째는 회사명
세 번째는 프로젝트명으로 보통 만든다.

ex) 네이버에서 진행하는 네이버 스포츠 개발
com.naver.sports

또한 Class를 생성 할땐 이름의 첫 글자는 항상 대문자로 만드는 것이 중요하다.
Java 프로그램은 보통 main 메서드가 시작점이 된다.

main만 작성해도 자동완성으로 메서드가 작성된다.

[main 메서드 자동완성]

또한 모든 자바 기반 프로그램은 클래스 내부 { } 중괄호 내부에서 동작된다.

Java 프로그램의 실행 과정

  1. Java 코드를 작성한다. (/java)
  2. JDK 설치 시 들어있는 javac(컴파일러) 가 .java 파일을 .class 파일로 번역한다.
  3. JVM 이 .class 파일을 로드하고 실행한다.
  4. JVM 은 바이트코드를 해석하여 각 OS에서 실행 가능한 기계어로 변환한다.
  5. 변환 된 기계어를 실행한다.

리터럴에 대해서

  • 리터럴은 "값" 을 의미한다.
  • 리터럴은 순수한 값으로서 정수, 실수, 문자, 문자열, 논리 등으로 구성이 되어 있다.

리터럴은 변수와 함께 작성이 되는데, 프로그래밍 쪽에서 변수는 변하는 수만 의미하는 것이 아닌 값을 저장하는 공간 으로 보면 이해하기 쉬워진다.

int x = 10;

이라는 코드를 보면
int 라는 정수만 들어갈 수 있는 공간에 x라는 이름을 주고, 그 안에 10을 넣는 방식이다.

리터럴의 형태

이번 문단에서는 형태들에 대해 나열해보려고 한다.

숫자형 : 정수를 담는 자료형

        byte b = 10;    // 1 byte
        short s = 10;   // 2 byte
        int i = 10;     // 4 byte
        long l = 10;    // 8 byte

숫자형 : 실수를 담는 자료형

        float f = 3.14f;    // 4byte
        double d = 3.14;    // 8byte

문자형

   char ch = 'ㅎ';

논리형 : 참/거짓

  boolean bl = true;
  boolean bl2 = false;

같은 영역 *(이하 중괄호 { })*에서 동일한 변수명을 사용하는 것은 불가능하다.

반대로 말해서 다른 영역일 경우, 겹치는 변수명을 사용하는 것은 얼마든지 가능하다.

변수의 선언과 초기화


변수의 선언

int num;

변수의 초기화

 num = 30;

변수의 선언과 동시에 초기화
int num2 = 10

형변환

형변환이란 데이터 타입(자료형)을 다른 데이터 타입으로 변환하는 과정을 의미한다.

형변환에는 두가지 방식이 있다.

  • 암시적(묵시적) 형변환
  • 명시적 형변환

명시적 형변환

데이터 타입을 직접 변환하는 명시적 형변환의 경우, 대입연산자 오른쪽에 있는 값 앞에 ( )괄호와 함께 데이터 타입을 적으면 값을 직접 변환할 수 있다.

double dnum = 99.99;
int inum = (int)dnum;

위 코드는 명시적 변환을 보여주며, double의 소수 부분은 int에 담을 수 없으므로 .99가 버려지게 된다.

명시적 형변환은 데이터 손실 가능성이 존재하기 때문에 컴파일러가 번역 시에 Error 를 발생시킨다.

암시적(묵시적) 형변환

자바가 자동으로 자료형을 바꾸는 것이다.

int num2 = 100;      //4byte
double dnum2 = num2; //8byte

위 코드는 int → double은 자바가 자동으로 변환해준다.

연산자

산술연산

+, -, *, %, /
산술 연산에는 위와 같은 연산자들이 쓰인다.

문자열이 포함된 더하기 연산은 유의해야 한다.
문자열은 + 연산을 만나면 피연산자를 문자열로 변환한다.

비교 연산

두 값을 비교하여 참/거짓을 반환하는 연산자이다.
==, !=, <, >, <=, >=

boolean 리터럴을 이용해 하나 이상의 "조건을 결합"하여 최종적인 참 또는 거짓을 평가한다.

증감 연산

변수의 값을 1씩 증가시키거나 감소시키는 연산자

++(증가), --(감소)

증감연산에는 전위 연산과 후위 연산이 존재하며, 앞에 붙냐 뒤에 붙냐에 따라 다르다.

  • 전위 연산
    시작하기 전에 연산하고 시작
  • 후위 연산
    다 끝내고 난 후에 연산
