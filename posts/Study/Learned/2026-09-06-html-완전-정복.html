배운 것

HTML 완전 정복: 기본 구조부터 폼 처리까지

부트캠프 강의에서 HTML의 기본부터 심화까지 모든 태그와 개념을 배우며 실습한 내용입니다. 웹의 뼈대를 만드는 HTML의 전체 과정을 정리했습니다.

2026-09-06

웹 개발의 첫 시작은 HTML을 이해하는 것이다. HTML은 웹사이트의 뼈대를 만드는 언어로, 모든 웹페이지의 기초가 된다. 부트캠프에서 HTML의 모든 주요 태그와 개념을 배우고 실습했다.

학습 내용

기본 개념

HTML(HyperText Markup Language)은 웹 페이지의 구조와 콘텐츠를 정의한다. 태그를 사용하여 텍스트, 이미지, 링크, 리스트, 테이블 등을 구성한다.

텍스트 관련 태그

제목(h1~h6), 단락(p), 줄바꿈(br), 글자 형태(strong, em, mark, u 등) 등을 학습했다.

목록 태그

순서 없는 목록(ul), 순서 있는 목록(ol), 설명 목록(dl)의 사용법을 배웠다.

표 태그

tr, th, td를 사용한 표 구조와 colspan, rowspan으로 셀 병합하는 방법을 학습했다.

영역 및 시맨틱 태그

block 요소(div)와 inline 요소(span), 그리고 header, nav, article, section, footer 같은 시맨틱 태그의 역할을 이해했다.

이미지, 미디어, 링크

img 태그의 src와 alt 속성, audio/video 태그, a 태그를 통한 하이퍼링크 기능을 배웠다.

폼 태그

form, input, select, textarea 등을 사용해 사용자 입력을 받고, GET/POST 방식으로 서버에 데이터를 전송하는 방법을 학습했다.

결과

HTML은 단순한 태그의 나열이 아니라 웹 문서의 구조와 의미를 담는 언어임을 깨달았다. 의미론적 HTML의 중요성과 웹 표준의 가치를 이해하게 되었다.
