설정

프로필 사진과 카테고리 목록, 비밀번호를 관리합니다. 변경 사항은 작업 폴더에 바로 저장됩니다.

ⓘ 이 기능은 Chrome / Edge 같은 Chromium 계열 브라우저에서만 동작합니다 (Safari, Firefox는 지원하지 않음). 먼저 블로그 작업 폴더(이 settings.html 파일이 들어있는 폴더)를 연결해주세요. 비밀번호가 설정되어 있다면 연결 후 비밀번호 확인 화면이 나타납니다.
⚠ 이 사이트는 서버 없이 정적 파일로만 동작하기 때문에, 비밀번호는 페이지 소스를 볼 수 있는 사람까지 완전히 막지는 못합니다. "아무나 실수로 못 건드리게" 하는 가벼운 잠금으로 이해해주세요.

비밀번호를 입력해주세요

프로필 사진

홈 화면 사이드바와 About 카드에 보여줄 프로필 사진입니다.

카테고리 관리

여기서 추가/삭제한 카테고리가 홈 화면 사이드바와 새 글 쓰기의 카테고리 선택 목록에 그대로 적용됩니다. 카테고리를 삭제해도 이미 작성된 글은 지워지지 않지만, 사이드바에서 그 카테고리로 필터링할 수는 없게 됩니다.

비밀번호 설정

새 글 쓰기 / 설정 페이지에 들어올 때 필요한 비밀번호입니다. 아직 설정되어 있지 않습니다.
